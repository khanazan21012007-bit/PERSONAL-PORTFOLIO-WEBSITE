# Professional Full-Stack Developer Portfolio

A clean, modern, and responsive personal portfolio website built with semantic HTML, CSS Flexbox/Grid, and vanilla JavaScript. Designed specifically for full-stack developers to showcase their projects, technical skills, education, and professional experience without any heavy frameworks or third-party AI widgets.

## Features

- **Responsive Design:** Fully optimized for mobile devices, tablets, and desktop screens with a mobile hamburger navigation menu.
- **Dark/Light Mode:** Built-in theme switcher allowing users to toggle between dark and light modes.
- **Project Filtering & Real-Time Search:** Interactive category filtering (All, Full-Stack, Backend) and live keyword search functionality across project cards.
- **Smooth Navigation:** Smooth scrolling navigation links and a "Back to Top" floating action button.
- **Interactive Contact Form:** Responsive contact section featuring real-time client-side input validation and success feedback state.
- **Semantic HTML & Clean CSS:** Modular CSS variables (`:root`) for easy theme management and custom styling.

## Built With

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, Flexbox, CSS Grid, variables, and responsive media queries.
- **JavaScript (ES6+):** DOM manipulation, event listeners, filtering, and theme logic.
- **Icons & Fonts:** FontAwesome and Google Fonts (Plus Jakarta Sans).
